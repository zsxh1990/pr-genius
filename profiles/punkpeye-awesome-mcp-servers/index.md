## 3. 贡献模式

**添加新 MCP server**：
1. Fork → 编辑 README.md → 添加条目到对应分类
2. 格式：`- [Server Name](url) — one-line description.`
3. **必须有 Glama badge**（经验教训：#10393 初次提交被要求补充）
4. 提 PR，通常 1-3 天 merge

**关键教训**：
- Glama badge 是必须的（maintainer 会要求补充）
- 分类要准确（不要硬塞到不相关的分类）

---

## 4. 提 PR 方向

### 🥇 添加新的 MCP server 条目

- 扫描 GitHub 上的 MCP server 项目
- 确保有 Glama badge

### 🥈 修复 broken links

- 2134 个 open issue 中很多是 link checker 报告
