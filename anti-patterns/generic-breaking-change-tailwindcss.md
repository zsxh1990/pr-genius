# Tailwind CSS Breaking Change

## Pattern

Tailwind CSS requires discussion for breaking changes.

## Applicability

Universal — applies to all repository sizes (large, medium, small).

## How to Avoid

1. Open discussion first
2. Get approval
3. Then submit PR
