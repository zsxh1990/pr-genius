## 反模式说明

**问题**: 文档描述与代码实现不一致

### 关键特征

- README 描述的功能已废弃或未实现
- API 文档与实际接口不符
- 示例代码无法运行
- 配置说明过时
- 注释与代码逻辑矛盾

### 为什么被拒绝

1. **用户体验差**: 用户按照文档操作却失败
2. **信任度下降**: 文档不可靠影响项目声誉
3. **维护负担**: 不一致的文档需要额外解释
4. **贡献障碍**: 新贡献者被错误文档误导

### 如何避免

1. **同步更新**: 修改代码时同步更新文档
2. **文档测试**: 
   - 示例代码可运行
   - 配置说明可验证
   - API 文档与接口一致
3. **定期审查**: 
   - 检查 README 是否过时
   - 验证示例代码
   - 更新 changelog
4. **文档驱动开发**:
   - 先写文档/注释
   - 再实现代码
   - 确保一致

### 检查清单

- [ ] README 描述与实际功能一致
- [ ] API 文档与接口定义一致
- [ ] 示例代码可正常运行
- [ ] 配置说明准确
- [ ] 注释与代码逻辑一致
- [ ] CHANGELOG 记录了变更
