# Large Repo: Docs-Only PRs

## Pattern

Docs-only PRs in large repos have the highest merge rate because they are low-risk and easy to review.

## Success Strategy

1. Fix typos, improve examples, update outdated docs
2. Keep changes small and focused
3. No code changes needed

## Evidence

- vercel/next.js: docs PRs merge within days
- fastapi/fastapi: docs PRs merge within hours
- huggingface/transformers: docs PRs welcome

## Applicability

All large repos
