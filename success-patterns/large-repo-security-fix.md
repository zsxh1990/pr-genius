# Large Repo: Security Fixes

## Pattern

Security fixes in large repos are high priority and merge quickly.

## Success Strategy

1. Report security issue privately first
2. Follow security policy
3. Submit fix with CVE reference if applicable

## Evidence

- kubernetes/kubernetes: security fixes via security advisory
- tensorflow/tensorflow: security fixes prioritized
- huggingface/transformers: security fixes merge quickly

## Applicability

All large repos
