# Large Repo: Test Coverage Improvements

## Pattern

Adding tests for untested code paths is welcome in large repos.

## Success Strategy

1. Find untested code paths
2. Add comprehensive tests
3. Keep tests focused and clear

## Evidence

- kubernetes/kubernetes: test improvements always welcome
- pytorch/pytorch: test coverage PRs merge quickly
- tensorflow/tensorflow: test additions valued

## Applicability

All large repos with test infrastructure
