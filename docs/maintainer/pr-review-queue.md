# Maintainer PR Review Queue

_Generated by `prgenius review-queue` (v1.5.0 maintainer view) — 2026-08-04_

## Purpose

Surface maintainer-facing action decisions for open PRs. Each PR is routed to one of 5 maintainer actions:

- ✅ `READY_FOR_REVIEW` — DCO/audit/shape 绿，可人工 review
- ⏸️ `WAIT_FOR_AUTHOR` — DCO/CI/requested changes，等作者
- 🗑️ `CLOSE_DUPLICATE` — 重复或已有 clean-room absorption
- 🛑 `CLOSE_STALE_OR_RISKY` — DCO failed + shape-risk / destructive rewrite
- 🤔 `HOLD_MAINTAINER_DECISION` — workflow/core/security/roadmap，需 maintainer 判断

## Run

```bash
PYTHONPATH=./prgenius/src python3 -m prgenius review-queue \
    --prs-file /tmp/open-prs.json \
    --write-digest docs/maintainer/pr-review-queue.md
```

Input JSON shape:

```json
[
  {
    "repo": "Ikalus1988/MisakaNet",
    "number": 793,
    "title": "fix: ...",
    "author": "contributor",
    "body": "PR body (full text)",
    "labels": ["..."]
  }
]
```
